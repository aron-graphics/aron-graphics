Zeiger über einen Tag: der Tooltip folgt auf zwei Federn. Klick wählt ihn aus. Über ein Legendenfeld: alle anderen Stufen treten zurück, Klick hält sie fest. Mit Tab ins Raster, dann ← → wochenweise, ↑ ↓ tageweise, Enter wählt.

vs-calendar-heatmap aus dem Vuesax-Katalog, unverändert. Die Zahlen stehen in contributions.json, die ein Workflow jede Nacht erneuert. Der Baustein stuft nach dem vollsten Tag ein, die Karte auf dem Profil nach Quartilen — darum liegen dort manche Tage eine Stufe höher. Seine Beschriftungen stehen fest auf Englisch; deutsch.js stellt sie um, ohne die Katalogquelle anzufassen.
